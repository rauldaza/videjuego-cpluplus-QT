# Rick & Morty Game - C++ Project with Qt

This project is an arcade-style video game developed in C++ using the Qt framework. The game includes multiple levels, selectable characters, enemies with different behaviors, obstacles, and a scoring system.

## Main Features

- **Intuitive graphical interface** using Qt Widgets and QGraphicsView.
- **Playable characters**: Rick and Morty, each with their own sprite and logic.
- **Varied enemies**: Aliens and escorts, with their own movements and attacks.
- **Bullet and collision system**: Projectiles from allies and enemies, impact detection, and life management.
- **Dynamic obstacles** in advanced levels.
- **Game session persistence**: Logging game results in a history file.
- **Event handling**: Supports keyboard and mouse events.
- **Object-oriented design**: Modular and reusable code.

## Project Structure

- `Rick_Morty/`: Main source code (classes, game logic, UI).
- `build-*`: Build folders generated by Qt Creator.
- `README.md`: This file.
- `Historial.txt`: Game session log.

## Demonstrated Skills

- Object-Oriented Programming in C++.
- Advanced use of Qt for graphical interfaces and event logic.
- Dynamic memory and graphic resource management.
- Game logic implementation and collision detection.
- Data persistence in text files.

## Execution

To compile and run the project:
1. Open the `.pro` file in Qt Creator.
2. Compile the project.
3. Run from the environment or the generated executable.
